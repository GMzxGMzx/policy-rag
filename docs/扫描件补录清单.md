# 扫描件补录清单（7 份）

你放的 13 份文件里，**7 份是纯图片扫描件**（PDF 内没有任何字体资源），文本抽取拿不到一个字。
这 7 份不补，语料就少一半。

补录原则：**优先找文字版，OCR 是最后手段。** 顺序如下，成本从低到高：

1. 官网 HTML 正文 → 复制即可，准确率 100%
2. 官网 Word/PDF 附件（.docx/.doc）→ 直接丢进 `data/raw/`，本项目原生支持 docx
3. 其他地市的转发页（常有全文转载）
4. OCR 已导出的图片（`data/ocr_pages/`，63 张已就绪）

## 二、通用检索技巧（下次自己补文件时用）

| 技巧 | 写法 | 说明 |
|---|---|---|
| 按文号精确搜 | `"苏建函建〔2024〕63号"` | 文号是最强指纹，比标题可靠 |
| 限定站点 | `site:gov.cn 建筑劳务 动态核查` | 只出政府站 |
| 找转发页 | `"苏建函建管〔2023〕371号" 转发` | 地市转发页常带全文，且是 HTML |
| 找 docx | `文件名 filetype:docx` | Word 版最省事，直接入库 |
| 查现行有效 | 发文机关官网「政策文件」栏目 | 优先于第三方转载站 |

**判断标准**：看到 `.docx` / `.doc` 直接下载；看到 `.shtml` / `.html` 复制正文；看到 `.pdf`
先判断是不是扫描件（打开后选中文字试试，选不中就是扫描件）。

## 三、补录之后怎么跑

```bash
# 1. 用导入工具把网页正文变成规范语料（会自动识别标题/文号/机关/日期）
python -m scripts.import_web_text --file 下载的页面.html
#   自动识别不准时手工指定：
python -m scripts.import_web_text --file body.txt \
  --title "关于做好2024年第一季度全市建筑劳务企业动态核查工作的通知" \
  --doc-no "苏建函建〔2024〕63号" --issuer "苏州市住房和城乡建设局" --date "2024-02-20"

# 2. 体检，确认都识别对了
python -m scripts.inspect_corpus

# 3. 重建索引 + 重跑评测
python -m scripts.ingest
python -m scripts.evaluate --tag with-ocr

# 4. 对比上一轮，看指标变化
python -m scripts.evaluate --baseline data/eval/runs/<上一轮的>.metrics.json
```
